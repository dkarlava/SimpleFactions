## Objective
This plugin is modeled after classic faction plugins. Essentially a land claim system with extra steps.

Too often factions plugins attempt to implement complex logic and overhauled configs that take forever to config, and they **still** never feel right.
This plugin is intended to provide bare minimum configuration to allow for rapid deployment and with reliable functionality.
